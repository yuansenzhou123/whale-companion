# 群聊、私聊与机器人自身发言的共同记忆（v2）

共同记忆保留实际聊天中的各方原话及机器人当时生成的回复，不再只索引主人本人。每条带发言角色、说话人、原会话和原时间。旧机器人回复是“当时说过这句话”的证据；不代表其中描述的现实经历真的发生，也不把旧语气当成新的人设示例。

原始会话仍按会话存在 data/store.json。持续更新的本地索引为 data/shared-memory.json（version 2）。启动时把现存记录和v1索引关联进来，之后用户消息与机器人回复都在写入存档时同步索引，不额外向模型批量发送历史。每会话最多保留2000条，总计最多20000条，模型每次按问题检索最多16条相关发言并带上相邻问答，记忆正文有大小限制。

在已认证主人的微信私聊里，可以回顾机器人与其他好友、群聊中的相关对话。群里只读取该群更早的记录、这位主人的相关本人信息及适用的表达要求；不会把其他好友的私人聊天发到群里。其他人也不能因改成同名而读取主人的私人记忆。

当前聊天仍是主要上下文。需要回忆当前会话早期内容时，也能检索已超出普通上下文窗口的片段。其他会话、当前会话更早片段分别标明。查询提到某人时会按发言者和会话线索检索；本人明确确认过的多种称呼可用于理解旧记录中的提及对象，但昵称绝不替代微信身份认证。含糊指代可利用本轮最近几句作为检索线索。

检索带回相关发言的前后问答，因此能区分“别人当时问了什么”和“机器人当时回了什么”。已有自身原话时，不得无依据否认。截图里的“本人/对方”只表示截图左右位置，不能默认“本人”就是当前发图者。

遗忘标记、按来源重置继续保留，密码和密钥等凭据不索引。已明确让忘掉的内容，不因重启回扫而恢复。当前实现按文字、人物、称呼和前后文线索检索，不能保证无限期记住所有内容或每次都命中。原始存档中已经不存在、且旧索引也没有保存的内容不能凭空恢复。

可以通过 /api/memory/status 查看实际索引版本、数量和自身回复数量。实际模型请求日志只记录本轮带入的记忆片段数、来源数、自身回复数、其他发言者片段数，不记录记忆正文或Key；以此检查“记录存在但没有送进模型”的情况。
