# 鲸鲸陪看：本地哔哩哔哩客户端

桌宠现已使用 `live2D/DS鼠控版.zip` 里的真实 Live2D 模型，包含透明背景、呼吸眨眼、鼠标跟随及自带表情。在原项目上使用独立桌宠和采集进程，共用现有模型、人设及微信桥接。无需重装系统或安装浏览器扩展。

## 第一次使用

1. 打开本地 **哔哩哔哩客户端**，进入视频播放界面。
2. 双击项目根目录的 **启动陪看桌宠.bat**。它会启动服务和桌宠，自动启用陪看。
3. 把 B站客户端切到前台播放；自动锁定整个客户端内部画面，无需手动选择。
4. 回到 B站客户端播放视频。桌宠会在旁边改变表情，偶尔说一句短评。右键桌宠，选 **说说这段** 可手动触发。
5. 右键桌宠打开 **陪看设置**，确认关联的是自己的微信主人账号，微信桥接继续用原来的启动方式运行。

设置保存后立即生效，无需重新导入 v7 人设。主页面顶部也有「陪看」入口。

## 当前行为

- 优先读取 Windows 媒体会话里属于 B站客户端的标题、播放进度及暂停状态。当前电脑上已确认可读取。
- 每约 35 秒把B站客户端窗口的一张压缩画面交给现有识图模型，再由聊天模型判断表情及短评。短评默认至少间隔 120 秒，可调整。
- 本版是定时看画面，能读取画面内的字幕；**不采集声音，也不保证理解采样间隔内的所有剧情**。视频本身有字幕时效果更好。
- 仅客户端在前台时采集。切走、最小化或暂停时不累计观看时间；恢复后继续。没有可读媒体进度时，仅保守记录前台可见片段。
- 每次采集都重新读取 B站客户端窗口位置及尺寸，移动、缩放、全屏和切换显示器后自动跟随；只截客户端内部画面，不截整个桌面。旧版保存的框选坐标不再影响原生客户端采集。
- 桌宠不会定时抢焦点；双击可摸摸，拖动可换位置，右键菜单包含完整的表情、外观、道具和动作；提供暂停/继续、说说这段、自动评论开关、设置、隐藏及退出，托盘也可使用同一菜单。退出桌宠后，它启动的采集进程会一并退出。
- 画面只在内存中短暂处理，不存截图文件。设置页可关闭向识图模型发送画面；观看存档只保留时间、实际画面描述和短评。

## 表情、外观和动作

右键桌宠或托盘图标：

- **表情**：选择后固定表情；选「跟随陪看（自动）」恢复随视频变化。
- **外观**：切换发型、头箍、桌布、眼镜、贴纸；勾选表示启用，点同一项可关闭。
- **道具**：鲸鱼、手机、蛋包饭、画笔等；对应依赖自动启用，眼镜和手持道具的互斥选项自动替换。
- **动作**：点击播放一段动画或短暂姿势；播放完自动恢复，也可点「停止动作／恢复待机」。

外观、道具和固定表情自动保存，重启仍保留。动作期间使用的临时道具不会覆盖保存的选择。恢复外观、恢复道具和自动表情可分别操作。

## 微信里的观看回忆

默认至少实际观看 10 分钟，并采到可用画面后，才有回访素材。视频结束、暂停或离开客户端一会儿后，素材可供主动聊天使用。

仍需满足已有主动聊天条件：真实微信主人 ID、已有私聊记录、白天 09:00–22:00、微信私聊空闲约 60 分钟、每天最多 3 次、未回复不连续追问。**10 分钟是积累观看素材的门槛，不代表第 10 分钟立刻发微信。** 微信桥接必须运行；微信本身仍沿用原来的模拟操作方式。

观看回忆只提供给关联主人的微信私聊，不带入群聊和其他用户。正常回复也能接着实际看过的细节聊，避免凭标题编剧情。

## 暂停与排查

- 右键桌宠选择「暂停陪看」只停陪看；原有「一键终止」或 PageUp 会停服务、桌宠及采集。再次双击陪看启动器会解除全局暂停标记。
- 设置页显示「等待 B站客户端」：确认客户端在前台，并正在播放。
- 显示画面识别错误：检查原来的识图模型设置、模型能力和服务可用性。陪看复用识图配置，不会自动换 Key。
- 老服务还在运行且提示没有陪看接口：先关闭老服务，再用新的启动器打开。
- 故障记录：`data/live2d-pet-error.log`、`data/live2d-pet.stderr.log`、`data/companion-capture.stderr.log`、`data/companion-window-error.log` 及 `data/whale.log`。

Live2D 模型来源、表情对应和许可说明见 [Live2D 说明](../companion/desktop/LIVE2D-NOTICES.md)。原始压缩包保留，鼠控版自动加载，无需 VTube Studio 或摄像头。


隐藏桌宠后，再次双击启动器会重新显示原来的窗口；重复启动不会再开一个。窗口拖到屏幕外时，再次启动会移回可见区域。后台进程显示为 python.exe 和 node.exe。


右键菜单的「允许截图」勾选后立即生效，普通截图和录屏可包含桌宠；取消勾选后排除桌宠。默认沿用截图排除，选择会保存，重启后保留。允许截图时，桌宠也可能进入 B站陪看的采样画面，可把桌宠放到 B站窗口外。


## 微信桥接开关

桌宠右键菜单中的“微信桥接”按当前项目的实际进程显示勾选状态：运行时显示 √，点击关闭；未运行时不勾选，点击启动。处理期间临时禁用重复点击。

关闭只停止本项目的微信监听和重启守护，不关闭微信客户端，也不暂停桌宠、陪看或网页服务。再次点击可重新启动。桥接独立停止标记保存在 `data/WECHAT_STOPPED`，不会使用整项目的 `data/PAUSED`；显式启动桥接会恢复该开关。

状态以实际进程为准，不因旧心跳文件而误显示运行。其他项目副本的桥接不会被这个菜单停止。
