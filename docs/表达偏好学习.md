# 从聊天中学习表达偏好

v2 会识别已认证主人在微信对话中提出的说话方式反馈，结合当前会话相邻的真实回复理解指代。无需先打开“相处与约会”，原有完整人设、聊天 API、识图 API 保持原样。已学到的偏好也用于主动私信和桌宠短评，桌宠的 JSON 格式和当前视频证据要求继续保留。

只有疑似表达反馈才额外调用一次当前聊天模型进行语义整理，读取本条反馈、相邻回复及已有表达偏好，不回扫历史批量训练。普通聊天仍走原流程。整理请求单独使用最多 900 个输出 token、8 秒截止时间；正常聊天输出上限不变。识别失败不会保存臆测偏好，仍正常处理本条消息。

明确的纠正会保存成具体表达要求，在本轮及以后适用的回复中使用。肯定上一句时，只能收藏本会话中实际存在、明确被认可的机器人回复；不会创作新对话例子或把例句里的情节当成现实经历。模糊反馈、他人的要求、假设和凭据不会直接变成偏好。

用户明确限定的私聊、群聊及临时要求分别处理。未限定场景的偏好用于与这位主人聊天；明确交代的群聊表达习惯可用于群内回复，但私聊原话和认可例句不提供给群友。新的相反要求会替代旧项；可兼容的要求可以并存。短句偏好不会截断认真问题、技术解释或求助内容。

## 查看与撤销

打开 <http://127.0.0.1:8787/style.html>，或在人设页顶部进入“从聊天学到的表达偏好”。可查看当前有效要求、对应用户反馈、实际认可的回复，并移除单条、撤销最近一次学习、清空或暂停继续学习。暂停学习保留现有偏好的应用。

微信私聊也可以管理：

- `查看学到的说话偏好`
- `撤销刚才学到的说话偏好`
- `清空学到的说话偏好`
- `关闭学习表达偏好`
- `开启学习表达偏好`

本地存档是 `data/style-learning.json`，已被 Git 忽略。每位主人最多保留 24 条当前有效偏好，另保留有限的撤销历史；删除和清空会使在途整理失效，重启不会自动重新学习被删除的内容。正常的共同聊天记忆继续独立保存。

这项功能通过下一次模型请求的表达要求适应用户，不修改模型权重；效果仍取决于模型能否准确理解反馈并遵循要求。第一次开启不会伪称已经学会过去所有偏好，需要后续真实反馈逐步积累。日志以 `purpose=style_learning` 区分整理请求和正常聊天，只记数量、状态及提示词摘要，不记录偏好正文或密钥。
