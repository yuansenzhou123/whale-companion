# v3 朋友圈图文发表

适配用户提供的 Windows 微信合并布局：先进入侧栏“发现”，点击“朋友圈”，点击右上相机，选择图片，再填写文字并点击“发表”。不会把相机选图误当成直接打开纯文字编辑器。

配图需由主人单独授权。当前本机配置 actions.momentMedia.source 为 emotion；发行示例默认 none。程序仅使用本项目 emotion 目录内的图片，不读取任意桌面或相册照片。GIF 取首帧生成 data/moment-media/ 下的静态 PNG，原图保持不变。配图属于装饰，不是共同观看视频的截图，也不作为真实经历证据。

排队时把图片路径和内容校验值与任务绑定；执行前及执行中检查权限和原图有无变化。打开的文件选择器必须属于微信且为本轮新建，输入完整文件名并核对，再打开。识别新的朋友圈编辑窗口时也支持带“谁可以看”“发表”“取消”的未命名面板。不会改变谁可以看、提醒谁看等设置，不接管已有编辑窗口或用户草稿。

实际成功需要在本机自己的朋友圈记录里找到新增动态，正文一致且包含图片。无法核实时标记为结果未知，不自动重发；未点击发表时文案仍保留在项目任务记录中。旧的失败任务不会因升级自动重试；每天最多一次自主发表尝试的限制保持不变。

本次回归测试使用虚构控件和生成的测试图片，没有通过测试向真实微信上传或发表内容。真实客户端控件的兼容情况仍需在实际使用时核实，执行记录会注明失败阶段。
