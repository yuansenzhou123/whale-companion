# 相处与约会

入口是桌宠右键 **相处与约会**，或浏览器打开 `http://127.0.0.1:8787/relationship`。主聊天页和陪看设置页也有入口。只对启用的真实微信主人账号使用这些偏好；群聊、其他用户和未关联的网页聊天不会共享亲密内容。

## 已接入的功能

- **相处档案**：虚拟恋人/亲近朋友、专属称呼、亲昵程度、倾诉时的偏好。保存立即生效。
- **明确记忆**：可以手动记下小事、查看和逐条移除。
- **表达反馈**：记住少说套话、减少反问、不用主人称呼，以及用户喜欢的最近回复方式。
- **有具体由头的主动私信**：优先到期的关心事项，其次结束的约会或真实陪看片段，再接着最近实际聊过的话题。没有由头就保持安静，也可以在设置页关闭这个限定。
- **日常约会**：一起看视频、饭后文字聊天、安静陪一会儿。可设置 5–120 分钟，也可提前结束或取消。结束后只保留实际时段、收到的消息数量和真实采样画面，不编造一起看完整部视频的经历。

## 微信中可以直接说

| 说法 | 效果 |
|---|---|
| 以后叫我小蓝 | 保存专属称呼 |
| 记住：我不吃香菜 | 加入相处记忆 |
| 这句太官方了 | 减少正式套话 |
| 别总反问我 | 减少追问 |
| 不要叫我主人 | 自然称呼，不再用主人口癖 |
| 这句不错 | 收藏最近真实回复的表达方式；内容不当作事实 |
| 先听我说 / 帮我想办法 / 逗我开心 | 切换回应偏好 |
| 一起看视频 | 开启 20 分钟的视频陪看时段 |
| 饭后聊聊 / 陪我吃饭 | 开启 15 分钟的文字聊天时段 |
| 安静陪我 | 开启 20 分钟的安静陪伴 |
| 结束约会 | 结束当前时段 |

上述命令只在已启用相处功能的主人微信私聊中生效。昵称和反馈可以在设置页修改、移除。该页是设置入口，现有网页聊天没有自动绑定微信身份。

## 回访时间与发送规则

明确的第一人称计划（例如“我明天上午要面试”）会被保守记下。白天事情默认在对应日期 18:00 后问起；晚上事情默认在次日 09:00 后问起。可在页面里设置准确的回访时间。含“如果”“可能”、第三人称或疑问的句子不会自动生成事项。

说“面试结束了”“考试通过了”或“不想再聊面试”，会结束对应回访；页面里也可以标记完成或移除。

主动私信继续沿用原来的规则：微信私聊空闲约一小时、09:00–22:00、每天最多三次、未回复不连续追问、暂停和休息模式不发。未开启约会流程时，约会进行中不额外发主动私信，结束后的普通回访至少留三分钟再检查原有条件。开启约会流程后，约定内的开场、一次中段互动和及时收尾使用下方规则。设置了回访时间或结束了约会，**都不代表一定立即发送微信**。需要原有微信桥接保持运行。

发送成功确认后才写进聊天记录；发送失败的事项会重新等待，但仍受冷却和每天次数限制。没有收到发送确认时保守保留已安排状态，避免重复发。

## 这版约会的实际范围

看视频复用目前的定时画面采样；饭后聊聊使用微信文字；安静陪伴保留桌宠并停止额外主动私信。你主动发消息仍会正常回复。实时语音、歌曲音频理解和 GIF 私信发送留在后续阶段。

相处资料保存在 `data/relationship.json`；原人设、模型 Key 和历史聊天文件不被覆盖。设置页可以关闭相处功能，恢复原来的主动聊天行为。

## 主动邀请与约会流程

相处设置新增“允许她在空闲时主动邀请约会”和“开启约会开场、中段互动与收尾”，默认开启。仍可分别关闭。已启用的档案升级时保留原有称呼、偏好、人设和历史。

- 邀请在原主动私信条件满足时提出，仍需要空闲约一小时、白天、每天剩余次数和已认证的微信私聊。到期的关心事项、待处理的约会收尾和真实陪看回访优先。
- 每位主人48小时内最多一次邀请；一次有效两小时。成功发送确认后，直接回复“好呀”“可以”“开始吧”可接受，回复“今天不想”“改天吧”会收起。无回复不会催促。聊起别的话题后，后续的“好呀”不会被误认作接受。
- 也可在相处页面接受或婉拒邀请。只有接受或你直接要求开始，才启动计时、开启必要的陪看；邀请本身不会启动约会。
- 微信上说“别主动约我”仅关闭邀请，说“可以主动约我”可恢复。
- 开场：微信接受或直接开始时，回复即为开场；页面开始时先显示桌宠气泡，再在发送条件允许时发送微信开场。
- 中段：聊天和视频最多安排一次轻量互动，在约定时间过半、你开始后参与过聊天、最近安静至少90秒时才安排；视频还要求有本次实际采样内容。安静陪伴不安排中段消息。
- 收尾：到时自动结束并在桌宠显示道别。微信只在你回应过上一阶段、安静至少90秒且结束后15分钟内安排一次；未回复、已暂停、已静音、夜间、次数用完或过期时跳过，不在后来补发过期道别。手动结束有即时回复或桌宠气泡；取消会清掉约会气泡。
- 答应后的约会消息不再等待空闲一小时，但仍共享原来每天最多三次、09:00–22:00、暂停和未回复不追问限制。邀请也占用当天次数，普通的用户消息回复沿用原聊天规则。
- 发送先持久化领取，再等待真实确认。失去确认时不重发；约会阶段发送失败也不会连续重试。已安排的收尾不再叠加普通约会回访。

桌宠和页面会显示刚刚开始、一起待着、慢慢收尾的阶段。这里是线上文字/视频陪伴，不包含未来日期预约、语音通话或音乐播放。

## 自然相处

默认开启“从聊天里自然记住我的偏好和近况”和“自然陪伴”。页面的手动记忆、回访日期和固定时长收进可选补充；日常只需和已认证的主人微信账号正常私聊。

明确的喜好会直接记下；较复杂的习惯、计划和近况在聊天后后台整理，复用当前文字模型，不阻塞正常回复。只有置信度足够、能在这次用户原话中找到连续依据的记录才入库，不从群聊、第三人转述、假设、问题或模型自己说的话生成记忆。简单语句立即处理，复杂内容可能稍后才显示；抽取失败会跳过，不能保证每句话都记住。

说“我不吃香菜”无需额外加记忆命令；明确表达新的偏好会更新同主题自动记忆。页面可查看来源时间、逐条移除，也可说“忘掉香菜的事”，避免之后再主动提起。关闭自动记忆会停止整理和丢弃尚未返回的结果。只处理启用后新的聊天，不自动重扫旧聊天。

自然邀请会结合真正聊过的小事，沿用当前角色语气，不报固定分钟数。答应邀请，或说“陪我聊会儿”“陪我待一会儿”“陪我看视频”即可开始。继续聊天会延续陪伴，实际视频持续播放也会延续；说“我先去忙了”“不聊了”等可结束。长时间没有互动会自然收起，单次仍保留三小时后台上限，避免永远挂着。固定时长仍可在页面展开后选择。

自动回访仍受原来的每日次数、白天、未回复不追问和暂停限制，不会因为记住了事情就立即催问。此功能目前以已认证的微信私聊为主要聊天入口，桌宠负责陪看、气泡和状态显示。

自然模式下，新邀请最早隔一天再考虑；未回复或婉拒后至少隔两天，不因为网页上显示“允许邀请”就每天固定打卡。日常分享仍受视频分享白名单约束，本次不改变分享名单。

桥接运行状态现在记录接收轮询心跳。微信客户端重开、轮询长时间停住或连续读取失败时，会通过原有守护循环重新连接；不会仅凭进程存在就判定接收正常。状态文件只保存时间、计数和账号摘要，不保存消息正文。之前启动时监听到的账号可能与后来重开的微信账号不同，遇到此情况必须重新连接。
